IC惊现课程表接口

自开发ICM（INSTLAB Cloud Mobile）以来，我一直在尝试完善作业纸打印的功能，然而自初代版本至今，除了作业纸打印之外，其他功能板块均为暂未开放，当时我以为是占位符，也许agent并不真正理解IC，由于需求不是很大，所以我没怎么更新ICM，直到昨天才发布0.0.10版本，我允许agent完成了课程表功能的开放——果不其然，课程均正确渲染出来，尽管还有些问题，但我认为在我们看不到的IC的内部，存在着课程安排的API接口，才允许我们做课程表，如果是这样的话，ICM的功能将会比预期的多甚至比IC多。

阿里巴巴限时免费开放Qwen 3.8 Flash

最近a6api里的qwen3.8-flash都炸了，不太稳定，好在deepseek-v4.1-flash有了低价商户，且阿里巴巴在Qoder中开放了qwen-3.8-flash免费蹬到月底，我才得以继续工作。
