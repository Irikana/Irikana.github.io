初次使用Claude Code
作者： 薛柯道
创建日期： 2026年9月8日
文章性质： 信息文章
标签： 新闻

昨夜凌晨，我抱着试一试的心态打开Claude Code，突然发现不用登录了，然后借此机会投入了几块钱试了一下中转后的gpt-6-astra和claude-fable-5等模型，结果并不令人满意，二者画出来的鹈鹕骑自行车完全不及qwen3.8-flash，价格还非常的昂贵。

但无论如何，这是我第一次使用Claude Code来工作，也是我第一次使用Cil端Harness工作，所以这件事令我很是激动和兴奋，我随后还使用了Codex的Cil。

最近我发现对任何事物使用自己的称呼习惯和语言习惯去表达会某种程度上让交流变得很困难，所以我现在慢慢的向一种半实证用语状态逼近，所谓半实证就是指在生活过程中逐渐了解那些严格定义的语言，使其替换自己不恰当的语言，实际上这种状态很可能已经慢慢开始几个月了，不过由于该过程很缓慢，所以我没察觉出来。

昨天我们已经尝试过上了开学后的第一堂课，果不其然，我的上课状态令我非常担忧，我有些僵硬，背疼或吸不上气，根据以往知识，这是我的过度紧张导致的，我在课堂上一直想着这件事为什么会变成这样，结果是我觉得我过于在意课堂，即看重上课这件事，目前没有找到很好的解决方法。
