视觉组件标准

每个组件下方展示「实际渲染效果」和「对应代码」，方便直观对比参考。

本页最后同步：alpha-023（与 .trae/rules/visual-components.md 及 style.css / library-refit.css / library-dynamic.js 实际实现对齐）。

关键规则：

  • 海报位始终保持 1 个；新增海报新闻时替换左侧 poster，被替换的旧海报新闻降级为文字新闻插入右侧列表（若右侧已满 6 条则挤出最旧一条）
  • 文字卡片只放标题 + 日期，不放正文内容；data-date 格式 YYYY-MM-DD，用于排序（按日期降序）
  • 海报图片路径：./image/poster/{路径}/{文件名}.png；中英文主页的新闻卡片需同步添加

容量与排序规矩：

  • 左侧海报位 1 个，右侧文字列表 最多 6 条；始终按 data-date 降序排列右侧列表
  • 新增文字新闻 → 插入右侧列表，满 6 条挤出最旧
  • 新增海报新闻 → 替换左侧 poster，旧 poster 降级到右侧列表

5. 分级提示构件（.sl-pop）

用途：站场内所有「要告诉读者一句话，并且允许他关掉」的构件——入口引导、状态提醒、操作反馈。取代旧的知识馆浮窗 .knowledge-hall-float 与语言切换浮窗 .lang-switch-float。样式在 css/style.css「分级提示构件」段（StyleEnforcer 有兜底），行为在 js/library-dynamic.js 的 SlPop 模块。

三种形态（等级类名三形态通用）：

形态 类名 场景
小弹窗（右上角竖排）.sl-pop（放进 .sl-pop-stack）入口引导：知识馆、英文版
模态弹窗（居中带遮罩）.sl-pop[data-pop-modal]需要读者先看到再开始浏览的提醒：Alpha 建设状态
轻提示（顶部滑入自消）.sl-pop-toast操作反馈：收藏成功、侧栏已收起

三个等级：

等级 类名 语义 边线色
提示.sl-pop-tip引导、可选入口、中性告知var(--color-accent)（随配色变换）
通知.sl-pop-note事实性通知，不打断阅读#2e7d5b（暗色 #58b189）
警告.sl-pop-warn需要特别注意的建设状态 / 时效提醒#c0392b（暗色 #d97b6c）

形态一：小弹窗（右上角竖排）— .sl-pop + .sl-pop-stack

页头标题、关闭按钮与页脚「今日不再提示」复选框由 SlPop.wire() 自动补齐，页面只写 .sl-pop-body 主体。同一页面的多个小弹窗共用一个 .sl-pop-stack 容器竖排。

实际效果（三等级各一枚；示例已静态化放进容器，并省略 data-pop-key 以免被本页真实 SlPop 模块接管）：

知识馆

牧羊人图书馆的分馆，用于存放和查阅知识

前往知识馆
站点动态

通知等级示例：事实性提醒，不打断阅读。

建设状态

警告等级示例：仅限需要特别注意的状态，红色不得滥用。

HTML 代码（页面只写主体，页脚复选框与关闭按钮由 SlPop.wire() 自动补齐）：

<div class="sl-pop-stack" id="sl-pop-stack">
  <div class="sl-pop sl-pop-tip" data-pop-key="knowledge-hall" data-pop-title="知识馆">
    <div class="sl-pop-body">
      <p class="sl-pop-desc">牧羊人图书馆的分馆，用于存放和查阅知识</p>
      <a href="./knowledge-hall/index.html" target="_blank" rel="noopener noreferrer" class="sl-pop-link">前往知识馆</a>
    </div>
  </div>
</div>

使用说明：

  • 小弹窗必须放进 .sl-pop-stack 容器（右上角竖排，fixed 定位，宽 236px）；容器缺省时由 JS 补一个。禁止再各写 top 值——旧浮窗靠 top: calc(... + 170px) 手排，新增一个就要改一次样式
  • 整摞可拖走：拖动任一弹窗的页头（.sl-pop-head）生效（SlPop.bindDrag()）
  • 运行期追加小弹窗用 SlPop.card({ key, level, title, desc, href, linkText })，同样接受「今日不再提示」与 0 点刷新
  • 移动端（≤768px）容器钉右上、限宽 52vw、限高可滚，规则见 css/library-refit.css「3.2 移动端浮层编排」
  • 顶栏出现时容器 top 让出 var(--sl-topbar-h)，由 html.sl-topbar-on .sl-pop-stack 负责

形态二：模态弹窗（居中带遮罩）— .sl-pop[data-pop-modal]

写在正文流里，加载时由 SlPop.toModal() 搬进 .sl-pop-mask 遮罩居中显示；关闭时未勾选「今日不再提示」就把原区块放回文档流，无 JS 也可直接阅读。等级由来源区块的等级类名推断。

实际效果（展开后的模态形态静态模拟；真实运行时页脚「知道了」按钮为 .sl-pop-btn，Esc 与点击遮罩空白处同样可关）：

本站处于 Alpha 阶段，内容与结构仍可能调整。

HTML 代码（区块写在正文流里即可，模态与遮罩由 JS 生成）：

<div class="sl-pop sl-pop-warn" data-pop-key="alpha-status" data-pop-modal data-pop-title="Alpha 建设状态">
  <div class="sl-pop-body">
    <p class="sl-pop-desc">创建于2026.1.4<br>提醒正文……</p>
  </div>
</div>

形态三：轻提示（顶部滑入自消）— .sl-pop-toast

API：SlPop.toast('文字', 'tip' | 'note' | 'warn')。完整结构、行为与时序见第 13 节。

实际效果（三等级静态模拟，真实运行为 fixed 顶部滑入）：

收藏成功
已移除收藏
该内容已下架

调用代码：

SlPop.toast('收藏成功', 'tip');     // 提示（跟随配色）
SlPop.toast('已移除收藏', 'note');   // 通知（绿）
SlPop.toast('该内容已下架', 'warn'); // 警告（红）

「今日不再提示」存储契约

  • 每个带 data-pop-key 的弹窗，页脚自动出现复选框「今日不再提示」；勾上再关闭才写入 localStorage 键 sl_pop-snooze，值为 { 弹窗键: 'YYYY-M-D' }（月/日不补零）
  • 只记当天：次日日期不匹配即自动重新展示，无需清理
  • 页面一直开着跨过 0 点时，SlPop 的定时器与 visibilitychange 监听会就地放行（不必刷新）
  • 不想提供该选项的弹窗写 data-pop-snooze="off"
  • 弹窗必须可关闭，禁止任何「必须跳转才能关掉」的形态

规范要求与已废弃构件

  • 全站扁平化：border-radius 一律 0；等级色只出现在左侧竖条、标题与轻提示底色上
  • 正文里的 .sl-pop p 不参与两端对齐与首行缩进（否则模态弹窗文字会被推歪），豁免规则在 css/library-refit.css「4. 页面骨架」段
  • 红色只用于「警告」级；不得为普通通知滥用警告语气（见 project_rules.md 的警告框授权机制）

已废弃：.knowledge-hall-float / .lang-switch-float 及其 .kh-float-* / .lang-float-* 子件——style.css 中的定义已删除，新页面禁止使用。入口引导一律改用本节的 .sl-pop 小弹窗（语言切换入口对应 data-pop-key="lang-switch"）。

9.3 移动端顶栏下拉面板（必须用 display 收起）

  • ≤860px 时 .sl-panel 改为 position: static 进入文档流，此时只靠 visibility: hidden 隐藏仍然占位，会让「导航」「馆藏」还没点开就撑出展开后的长度（alpha-022 的实测缺陷）
  • 规矩：小屏 .sl-panel { display: none }，.sl-menu[data-open="true"] .sl-panel { display: block }；淡入过渡仅在桌面端（面板绝对定位）生效
  • 同类要求适用于一切「在文档流里折叠/展开」的构件：折叠态必须真正不占位（display: none 或 grid-template-rows: 0fr），不得只用 visibility/opacity

CSS 代码（library-refit.css，860px 媒体查询内）：

@media (max-width: 860px) {
  .sl-menu { position: static; }
  .sl-panel {
    position: static;
    /* 静态流里只靠 visibility 隐藏仍会占位：小屏菜单没点开时就已经撑出展开后的长度，
       所以这里显式收进 display，点开才占高度 */
    display: none;
    min-width: 0;
    max-width: none;
    border: none;
    box-shadow: none;
    background-color: var(--color-bg-subtle);
  }
  .sl-menu[data-open="true"] .sl-panel { display: block; }
}

实际效果：把本浏览器窗口收窄到 860px 以下，点顶栏汉堡展开「导航」菜单——未点开的下拉不再撑出空白。
