文章元数据注册表
创建于2026年6月14日
本页面是牧羊人图书馆所有文章元数据的统一管理参考。创建新文章或修改已有文章时，应以此页面的字段定义和标签体系为准。

元数据字段说明

文章顶部元数据 — .article-meta

每篇文章的 <main> 区域顶部必须包含 .article-meta 区块，按以下固定顺序排列字段：

字段 标签类名 必填 说明 示例
作者 .article-meta-label + .article-meta-value 是 文章的作者姓名。全站统一填写"薛柯道" 薛柯道
创建日期 .article-meta-label + .article-meta-value 是 文章首次创建的日期。格式统一为 YYYY年M月D日（不补零） 2026年5月19日
文章性质 .article-type-badge 是 文章的创作方式，四选一（录音/手写/信息/实验性）。见下方"文章性质"章节。性质不等于分类（分类见 library.html） 手写文章
标签 .article-tag 是 文章的内容属性标签，可多选。见下方"标签体系"章节。无合适标签时填写"无" 新闻 包含AI

文章页脚元数据 — .article-footer-meta

文章正文末尾的可选区域，用于补充说明、脚注、参考链接等。不是每篇文章都需要。

字段 必填 说明 示例
图注 可选 正文中图片/公式的说明文字，用 .article-footer-label 标注"图注：" 图I：重力提供向心力的圆周运动
脚注 可选 正文中上标引用的详细说明，用 .article-footer-value 直接填写 [1] 且捡起来时都处于非常低的电量状态
参考链接 可选 关联的其他文章或外部链接，使用 .ext-link 类 查看与AI的完整材料对话

页面日期 — .page-date

非文章页面（如图书馆入门、规则等）标题下方的创建日期标注。文章页使用 .article-meta 中的"创建日期"字段，不使用 .page-date。

文章性质

每篇文章必须标注一种创作方式（性质），使用 .article-type-badge 类。注意：性质与分类不同，分类指 library/ 下的目录（普通文章/作品文章/杂物文章/测试文章）：

性质 预览 含义
录音文章 录音文章 通过录音转文字创作的文章。作者口述录音，再整理为文字
手写文章 手写文章 通过手写转文字创作的文章。作者手写草稿，再整理为文字
信息文章 信息文章 直接打字创作的文章。包括新闻公告、更新说明等
实验性文章 实验性文章 主要用于测试某些东西的文章，可能具有较少的可读性

标签体系

标签用于标注文章的内容属性。一篇文章可以有零到多个标签。标签分为通用标签和属性标签两类：

通用标签 — .article-tag

标注文章的内容主题或用途分类：

标签 预览 含义 适用文章
新闻 新闻 网站功能更新、版本发布、重要事件公告等新闻性质的文章 知识馆上线、视觉组件标准已创建等

属性标签 — .article-tag.tag-*

标注文章的创作属性或内容状态：

标签 预览 含义 适用文章
包含AI 包含AI 文章内容包含AI生成或AI辅助创作的部分 语义化视觉组件更新、坐立不安·材料对话等
有删减 有删减 文章原始内容经过删减或修改后发布 SOTM I 2026 后记等
新增标签：如需新增标签，应先在本页面登记标签名称、含义和适用范围，再在文章中使用。新增通用标签使用 .article-tag 类；新增属性标签需同时在 CSS 中添加对应的 .tag-* 样式类。

标准 HTML 模板

文章顶部元数据模板 
<div class="article-meta">
  <div class="article-meta-item">
    <span class="article-meta-label">作者：</span>
    <span class="article-meta-value">薛柯道</span>
  </div>
  <div class="article-meta-item">
    <span class="article-meta-label">创建日期：</span>
    <span class="article-meta-value">YYYY年M月D日</span>
  </div>
  <div class="article-meta-item">
    <span class="article-meta-label">文章性质：</span>
    <span class="article-meta-value"><span class="article-type-badge">录音文章</span></span>
  </div>
  <div class="article-meta-item">
    <span class="article-meta-label">标签：</span>
    <span class="article-meta-value"><span class="article-tag">新闻</span></span>
  </div>
</div>
文章页脚元数据模板 
<!-- 图注 -->
<div class="article-footer-meta">
  <div class="article-footer-meta-item">
    <span class="article-footer-label">图注：</span>
    <span class="article-footer-value">图I：说明文字</span>
  </div>
</div>

  <div class="article-footer-meta-item">
    <span class="article-footer-value">[1] 脚注内容</span>
  </div>
</div>

</div>
