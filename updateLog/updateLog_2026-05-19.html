StyleEnforcer CSS 语法错误修复

- 修复 library-dynamic.js 中 StyleEnforcer 模块的 .quote-box-grey 样式注入字符串

- 错误原因：!important 被错误地放在 var() 函数内部（var(--color-bg-subtle,!important)），导致 CSS 解析失效

- 修复为正确语法：var(--color-bg-subtle)!important

- 同时修复 border 和 border-left-color 的同类错误

- 影响：暗色模式下 .quote-box-grey 引用框可能无法正确显示样式

- 涉及文件：js/library-dynamic.js — StyleEnforcer.init() 注入样式字符串

TOC 目录体验改进（TocFloat 模块 + IntersectionObserver 增强）

- 问题：原始 TOC 固定在页面顶部，向下阅读后想使用目录必须回到顶部

TOC 悬浮按钮触发阈值优化

- 问题：部分页面下滚动后悬浮目录按钮不显示，需放大到 125% 才出现

- 原因：触发条件为 rect.bottom < 0（TOC 完全滚出视口才显示），大屏短页面下 TOC 始终部分可见

- 修复：改为 rect.top < 60（TOC 顶部距视口顶部 <60px 即显示），滚动一小段即可触发

- 涉及文件：js/library-dynamic.js — TocFloat.init() scroll 监听阈值；.trae/rules/visual-components.md — 文档同步
