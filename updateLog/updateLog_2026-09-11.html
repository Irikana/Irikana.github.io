主馆变更

一、图书馆视觉精修（标题层级与内容卡片）

- 修正标题层级倒置：原先下级标题（三级 24px、四级 22px）大于一级标题（22px）、二级标题（20px），现改为逐级递减的一至四级阶梯（约 25 / 21 / 18 / 16.5px），一级标题下方保留主色细线，四级标题改为「小标题 + 横贯细线」的期刊式排法

- 全站正文字号、行距、段距统一由设计令牌控制；正文两端对齐并启用中文标点挤压，段首可缩进两字（可在顶栏设置中关闭），呈读出版物版式

- 阅读栏宽改为可调令牌（窄栏 / 标准 / 宽栏 / 全宽，默认 760px），页眉、页脚、正文同一节奏；文章列表由纯链接列表改为等宽卡片网格（自动换列，移动端单列），卡片左缘带主色标记、悬停有 1px 抬升与投影，配色全部取自主题变量

- 页眉页脚收口：页眉下沿线、页脚上沿主色粗线、版权与版本标识字号统一，元数据区（作者 / 日期 / 性质 / 标签）改为上下细线的信息条

二、全站冻结顶栏（新增）

- 顶部冻结一条导航栏：左侧为 Logo 图片 + 「牧羊人图书馆 / Shepherd's Library · 存放所有知识之地」文字部分，右侧为四个可向下展开的按钮：导航、馆藏、主题、联系

- 「联系」按钮图标由代码绘制（内联 SVG 信封 + 对话气泡），下拉内容为 QQ、微信、FaceBook 三项；其显示名、号码/ID、链接与备注一律来自站点配置文件 slywrite-config.json 的 contact 字段，作者可在 SlyWrite「设置 - 站点配置 - 网站联系方式」中填写，网站约 1-2 分钟后显示；未填写时该项提示作者尚未设置，不展示任何虚构信息

- 号码类条目点击即复制；链接类条目在新标签打开。移动端顶栏折叠为汉堡菜单，Esc 与点击空白处收起面板

三、多主题与免版权字体（顶栏「主题」下拉配置）

- 六套配色：经馆（靛青）、羊皮纸、月白、林间、梅雨、夜读，每套均含明亮与深色两组变量，深色下自动降低对比与亮度

- 明暗三态（跟随系统 / 浅色 / 深色）与原右上角主题按钮共用同一开关，互不冲突

- 五套字体方案：系统无衬线、系统宋体（默认，无需下载）、思源宋体 Noto Serif SC、Source Serif 4、EB Garamond，均为 SIL OFL 免版权字体，按需从 CDN 加载对应字重与子集，CDN 不可达时回退本地宋体/思源宋体，出版感不丢失

- 另可配置字号（紧凑 / 标准 / 偏大 / 特大）、行宽、首行缩进，并提供「恢复默认」；全部偏好仅存于本机浏览器 localStorage，不影响他人与站点内容

四、移动端动态浮层整改（挡视线问题）

- 问题定位：移动端此前只是把 PC 端的动态浮层缩小，多个浮层坐标重合并压在被阅读的正文上——主题浮动按钮与「回到顶部」按钮坐标完全相同（互相盖死，回到顶部在手机上根本点不到）；阅读工具条在手机上通栏横贯屏幕底部，永久压住最后一行正文，展开时又与右下按钮互压；便携式导航仪钉在顶栏下却没取消垂直居中的位移，收起态上半截藏进顶栏、展开态标题被裁出屏幕；悬浮目录面板固定 220px 宽，在 375px 宽的手机上盖掉近八成视宽；知识馆浮窗与语言切换浮窗叠在右上角正文上

- 处理原则：能从冻结顶栏进入的，一律不再占用浮层。手机上撤走站内搜索浮钮（顶栏「导航」内有站内搜索）、明暗切换浮钮（顶栏「主题」面板可切）、便携式导航仪与旧版移动导航条（功能由顶栏承担）；知识馆浮窗与英文版入口浮窗按站点规范继续以浮窗形式存在，但改为一个钉左上、一个钉右上、各自限宽四成四视宽，不再叠在右上正文上

- 保留的浮层重新编排为左右两条竖列并上下错开：右列自下而上为导航枢纽（16px）→ 回到顶部（64px）→ 收藏入口（112px）→ 目录按钮（160px），阅读工具条改为左下角自适应宽度小卡（收起时不再压住整行正文，展开时限高可滚动），收藏面板、目录面板与搜索结果统一改为贴边限高可滚的抽屉（目录面板满宽、最高四成视高）；目录按钮的隐藏动画由位移加缩放改为纯缩放，避免留下看不见的点击热区

- 修正三处失效的避让规则：知识馆浮窗的避让选择器原写作 .kh-float，页面真实类名是 .knowledge-hall-float，等于从未生效（浮窗连关闭按钮都被顶栏压住）；便携式导航仪补上取消位移与限高可滚；知识馆侧边栏在手机上改回常规文档流，撤销「强设一屏高」导致正文被整段推到第二屏的问题

- 顶栏折叠菜单补上限高与滚动：窄屏下「主题」下拉的最后一组选项此前超出一屏无法点到

- 整改只动 css/library-refit.css（新增移动端浮层编排段并修正避让规则）与顶栏样式，桌面端布局不受影响；旧式内联样式的导入页因运行时补挂该样式表而同样受益

工程变更

- 新增 css/library-refit.css：主题变量、字体方案、冻结顶栏样式、标题层级与卡片网格、减少动效适配；置于 css/style.css 之后加载，同名令牌以本文件为准

- 90 个引用 css/style.css 的页面在 head 中追加该样式表与一段主题预应用脚本（首屏绘制前把用户偏好写到 <html> 的 data-sl-* 属性，避免切换主题时的白闪）；8 个早期导入页（自带内联样式、不引用 style.css）由脚本运行时补挂样式表，顶栏与主题同样生效

- js/library-dynamic.js 新增 SitePref（偏好读写与生效）与 TopBar（顶栏构建、下拉面板、联系方式读取）两个模块，并在启动序列中优先于其他模块执行；原 Theme 模块的切换被 SitePref 挂钩，保证明暗状态单一来源

- SlyWrite 端同步：文章与知识馆模板生成时写入同样的样式表引用与预应用脚本；站点配置新增 tagColors（标签颜色）与 contact（联系方式）字段，旧配置文件缺失该字段时按默认处理；App 内容编辑器新增「内容页面」模式，非 library 文章的页面也可撰写式改正文与页面标题
