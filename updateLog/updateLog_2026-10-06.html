2026-10-06 · 正文标准表格与代码构件落地 · 段落字间距异常拉伸排版修复 · 算式防斜体与公式符号保护 · alpha-025

一、主馆变更

1. 正文标准表格排版规范与样式落地（解决表格无框线问题）

- 补齐 css/style.css 中对正文表格（.content-main table、.left-align table、.kh-content table、table.sl-table）的标准样式定义，实现折叠边框（border-collapse: collapse）、全宽容器自适应以及扁平直角（border-radius: 0）。

- 单元格（th / td）统一使用主题边框令牌 var(--line-width) solid var(--color-border) 与内边距，表头自动使用浅灰底色 var(--color-bg-subtle) 加粗呈现，偶数行自带极微弱斑马纹，明暗双色通道无缝自适应。

- js/library-dynamic.js 的 StyleEnforcer 模块同步注入表格兜底防护网。

2. 行内代码与代码块视觉组件补齐（解决 code 仅变字体无修饰问题）

- css/style.css 为行内代码（code）配置专属样式：采用强调色文字（var(--color-accent)）、微底色（var(--color-bg-subtle)）与边框（1px solid var(--color-border)），外加适度内边距与直角边缘，提升正文辨识度。

- 为多行代码块（pre / pre code）配置卡片容器、4px 强调色左侧重点边线以及横向溢出滚动（overflow-x: auto）。

- StyleEnforcer 安全网同步补齐行内代码与代码块防护规则。

3. 正文排版与换行优化（解决特定行字间距异常过宽问题）

- 深入排查发现：css/library-refit.css 中对正文段落启用了 text-align: justify（两端对齐）与 text-justify: inter-ideograph。当段落内遇到未折行的较长字符序列（如算式 15+15+5=35*31*2=2170元、长英文单词或公式）被整体推至下一行时，上一行因剩余汉字较少，两端对齐算法强行将空白分配至各个汉字之间，诱发「字间距突然变宽」的视觉现象。

- 在 css/library-refit.css 的正文段落规则中补充 overflow-wrap: break-word 与 word-break: normal，允许长算式与英文词安全断行，消除空白空洞与字间距异常拉伸问题。

4. 存量文章排版与算式标记修复

- 修复最新新闻《计算生活费记录》（Calculate The Allowance Record.html）中因 Markdown 解析将算式星号误认为斜体标记而产生的残留 <em> 标签，恢复为字面算式。

5. 视觉组件展示页同步

- library/visual-components.html 逐节新增「18. 正文表格 — table / .sl-table」与「19. 代码与代码块 — code / pre」的实际效果预览、HTML 与 Markdown 模板，并同步更新版本说明至 alpha-025。

6. 全局版本号递增

- js/library-dynamic.js 中的 var Ver 升级至 alpha-025。
